About 60 seconds. The user signs in with a secure server-side session, optionally with two-factor, and talks to the copilot agent, which runs on OpenAI's Responses API with function calling. Before anything reaches the model, names, emails and account numbers are replaced with tokens, and the provider is told not to store the conversation. The model can only call tools, and every tool call goes through a policy gate on our server that checks the user's role against the tool's tier. Tier zero reads data and tier one gives advice; both run on deterministic finance engines. Tier two is any action with real-world effect, and it can only create a request in the approval queue. A human approves it in the app; only then does the sandbox execute it. Everything is written to a hash-chained audit log.
