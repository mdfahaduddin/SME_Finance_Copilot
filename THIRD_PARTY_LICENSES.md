# Third-Party Components

SME Finance Copilot uses the following open-source components. All are under permissive licenses (MIT, BSD, Apache-2.0, ISC) except two LGPL-3.0 libraries, noted below. Versions are pinned in `backend/requirements.txt` and `frontend/package-lock.json`. Licenses were read from each installed package's metadata.

## Data and services

- **All business data is synthetic,** generated by `backend/seed/generator.py`. Businesses, people, customers, suppliers and lenders are fictional. Email domains use the reserved `.example` TLD.
- **Chart palette:** a validated categorical reference palette, checked for colour-vision-deficiency separation and contrast.
- **OpenAI API:** used under OpenAI's API terms with the team's own key; conversations are sent with `store=false`.
